Frequently asked

Resource FAQs.

What kind of resources will be available?

The resource library is designed for notes, worksheets, revision material, practice questions and other academic resources published by Mentora Edge.

Which classes are covered?

The resource structure is designed around Classes VI–XII, covering Middle School, Secondary and Senior Secondary levels.

How will new resources be added?

The long-term plan is for published resources to be managed through the Mentora Edge resource management system and then displayed in the public resource library.

Will resources be available as PDFs?

Resources can be designed to support downloadable files such as PDFs, alongside online resource pages where appropriate.

Can I find a specific chapter?

Use the resource search and category filters to find available material. As the library grows, chapter-level resources can be added to the same system.
